따라가방 계정 삭제 안내

따라가방(CulturePath) 계정과 연결된 데이터를 삭제하려면 앱 안에서 직접 탈퇴하거나, 앱을 사용할 수 없는 경우 아래 이메일로 삭제를 요청할 수 있습니다.

앱에서 즉시 탈퇴하기

  1. 따라가방 앱에서 로그인합니다.
  2. 내 정보 → 계정 관리 → 회원 탈퇴를 선택합니다.
  3. 삭제 내용을 확인하고 탈퇴를 완료합니다.

이메일로 삭제 요청하기

가입할 때 사용한 이메일 계정으로 요청해 주세요. 이메일 본문에는 가입 이메일, 닉네임, 가입 방식(이메일 또는 Google), 그리고 “계정과 관련 데이터 삭제에 동의합니다”라는 문구를 적어 주세요. 요청은 확인 후 7일 이내 처리합니다.

비밀번호, Google 인증 토큰, 앱의 인증 토큰은 절대 보내지 마세요.

계정 삭제 요청 이메일 보내기

문의 이메일: culturepath.support@gmail.com

삭제되는 데이터

  • 계정 정보와 로그인 식별 정보
  • 사용자가 만든 공개·비공개 코스와 코스 장소
  • 좋아요와 코스 완주 기록
  • AI 채팅 세션

다른 사용자가 이미 복제한 코스는 유지되지만 원작자 표시는 탈퇴한 사용자로 익명화됩니다. 별도로 보존하는 사용자 데이터는 없습니다. 삭제가 완료된 계정과 데이터는 복구할 수 없습니다.
