# CulturePath 문서 아카이브

완료된 PR의 판단 근거, 일회성 검증 결과, 외부 디자인 도구 프롬프트처럼 매 작업마다 읽을 필요는 없지만 장기 보관할 가치가 있는 문서를 둔다.

## 이용 기준

- 현행 작업은 상위 [`docs/README.md`](../README.md)와 [잔여 작업 로드맵](../HWANG_CHANWOO_REMAINING_PR_ROADMAP.md)을 먼저 읽는다.
- 과거 결정의 원인, 검증 표본, 디자인 인계 조건을 추적할 때만 이 디렉터리를 읽는다.
- 아카이브 문서를 현재 계약처럼 해석하지 않는다. 충돌하면 상위 디렉터리의 현행 계약과 실제 소스코드가 우선한다.
- 보존 문서는 삭제하지 않고, 내용이 바뀌면 현행 문서에서 변경 이유와 대체 계약을 기록한다.
